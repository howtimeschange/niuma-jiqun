# 牛马集群

一个面向 Codex 的协作 skill：以当前会话为总控，按任务边界组织子代理，并在需要时协调关联项目。

## 能做什么

- **开发、修复和审查**：优先考虑在当前会话中使用子代理；适合独立检查的审查交给未参与实现的子代理。简单任务直接完成。
- **跨项目协同**：需要关联项目共同开发、接口联调或配合测试时，可在获得相应授权并符合工具要求的前提下，在对应项目创建会话。
- **跟踪与验收**：总控检查实际产物、最终差异和验证证据，报告完成情况与未验证部分。

技能不会替代当前环境的工具限制或用户授权。提交、推送、部署、外部写入、创建会话和创建 worktree 等操作遵循各自的权限边界。

## 安装

将仓库克隆到 Codex 的技能目录：

```bash
git clone https://github.com/howtimeschange/niuma-jiqun.git ~/.codex/skills/niuma-jiqun
```

如果目标目录已存在，请先检查并备份其中的内容，再选择合适的方式更新，避免覆盖本地修改。安装后重新打开 Codex，或按当前客户端支持的方式刷新技能列表。

## 使用

在 Codex 中明确调用 `$niuma-jiqun`，并描述目标、项目范围和验收标准，例如：

```text
$niuma-jiqun 帮我实现这个功能，并安排独立审查；保留现有无关改动。
```

涉及其他项目时，说明项目位置、接口或协作目标，以及允许的操作。是否能创建新会话或使用子代理，取决于当前环境和用户授权。技能中记录了模型偏好，实际模型选择仍受工具和用户指令约束。
